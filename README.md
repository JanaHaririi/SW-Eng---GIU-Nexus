# SW-Eng---GIU-Nexus
GIU Nexus is an AI-powered full-stack web application that helps university students find internships and jobs while giving recruiters a smarter, faster way to discover the right candidates. 

What it is: A web platform called GIU Nexus that helps university students find internships and jobs.

The "Wow" Factor: It uses AI to automate and improve the hiring process.

For Students: The AI automatically reads your bio, extracts your technical skills, and recommends the best job matches for you.

For Recruiters: The AI instantly categorizes their job postings so they don't have to guess the right tags.

The Tech: It is built from scratch using the MERN stack.
